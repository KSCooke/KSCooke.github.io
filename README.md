# kscooke.github.io

Kevin Cooke's personal site and CV: https://kscooke.github.io/

Plain HTML and one stylesheet, no build step (`.nojekyll` makes GitHub Pages serve the files as they are).

- `index.html`: the CV. Each job is one `<div class="entry">` block; copy one to add a job.
- `projects/homelab/`: the homelab project write-up and the privacy policy for the homelab-backups Google app
  (both URLs are registered on that app's Google OAuth Branding page, so keep them working).
- `style.css`: the whole design. Print the CV page (Save as PDF) for a résumé copy.

Everything here is public. Don't add a phone number, private email or anything from the homelab's internals.
